Comunicación visual

Tarjetas para comunicar. Saluda, elige, pide ayuda y expresa necesidades con palabras, gestos o señalamiento.

Volver a la plataforma

1. Saludar

👋

Puedo decir “hola”, mover la mano o señalar esta tarjeta.

2. Elegir

👆

Quiero: ☐ leer ☐ dibujar ☐ moverme ☐ descansar

3. Pedir ayuda

🆘

Necesito ayuda con: __________________________

4. Expresar una necesidad

💬

Necesito: ☐ agua ☐ pausa ☐ silencio ☐ explicación

Para la persona acompañante

Permite responder hablando, señalando, escribiendo o usando objetos. Divide la actividad, ofrece una pausa y evita corregir con prisa. Este material educativo no sustituye una valoración profesional.
